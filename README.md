# Echo Clock App (Flutter)

Echo Show 5（Android 11改造）向けのシンプルな2×2ダッシュボードです。
Android 端末であれば Android 7.0 以降であればどの端末でも動きます。

現在のバージョン： **v4.2.6**

## 表示内容
- 左上：大きな時計（時分秒）タップでアラーム設定
- 右上：日付・曜日（日本語）タップで今年の残り日数、長押しで今週の残り日数
- 左下：現在天気（Open-Meteo API・APIキー不要）最高・最低気温と降水確率つき。タップで明日の天気（降水確率つき）、長押しで地域変更
- 右下：ポモドーロタイマー（旧：画像スライドショー）

## ポモドーロタイマー（v3.2〜）
- タップ：スタート／一時停止
- 長押し：設定（集中 15/25/30/50分、休憩 5/10/15分、長い休憩 15/20/30分）とリセット
- 集中が終わると音が鳴って休憩が自動で始まります
- 休憩が終わると音が鳴って、集中はタップ待ちになります（夜通し回り続けないため）
- 集中4回ごとに長い休憩になります
- パネルの色で状態が分かります（集中中＝黄色 #F9E778、通常時＝ #5C526A。通常時は暗い背景に合わせて文字が白系になります）
- 終了音はポモドーロ設定で選んだ『キュアット解決！』のセリフが鳴ります（アラーム音とは別々に選べます）

## 使い方

1. Flutterがインストールされている環境でこのフォルダを開く
2. `flutter pub get`
3. 実機またはエミュレータで `flutter run`
4. APKを作りたい場合：`flutter build apk --release`

## アラーム音を変更したい場合

1. アラーム音は `assets` フォルダの `wakeup_miracle.wav` / `wakeup_eclair.wav` / `wakeup_alcana.wav` / `wakeup_all.wav`（ウェイクアップタイムのセリフ）です。
2. ポモドーロの終了音は `curette_answer.wav` / `curette_mystic.wav` / `curette_miracle.wav` / `curette_eclair.wav` / `curette_alcana.wav` / `curette_all.wav`（『キュアット解決！』のセリフ）で、ポモドーロ設定から選びます。
3. 現在入っているのは仮のチャイム音（ピンポーン）です。そのまま使う分には問題ありません。本物のセリフ音声に差し替える場合は、同じファイル名で `assets` フォルダに入れてください。
4. wav ファイルはローカル専用です（`.gitignore` で Git 管理から外しています）。別の環境に移すときは wav も一緒にコピーしてください。
5. 設定画面の「試す」ボタンでその場で試聴できます。再生に失敗した場合は、ファイル名と理由がダイアログに表示されます。

  - エクレール：「エクレールのウェイクアップタイム！」

- 初回起動時に「通知」と「正確なアラーム」の許可を求めるダイアログが出ることがあります。許可するとシステム通知が使えます。（許可しなくてもアプリ内アラームは使えます）
- システム通知の音は端末の通知音です。選んだ音声ファイルそのものは通知では鳴らせません。

## v3.3〜の変更
- 設定の保存：アラーム時刻・サウンド・地域・ポモドーロの時間と進み具合がアプリを再起動しても残ります。
	（ポモドーロは一時停止状態で復帰。完了セット数は日が変わるとリセット）
- 夜間モード：23時〜6時は自動で画面が暗くなります。
- 焼け対策：表示全体が1分ごとに数pxだけずれます。
	有機EL（OLED）端末で使う場合のためです。

## 注意
- 天気は30分ごとに自動更新します。
- アラームはシステム通知にも登録されますが、ポモドーロはアプリが起動している間だけ動作します。
- アラームは一回限りです。
	鳴り終わると自動で解除されます。（毎日の繰り返しには対応していません）
- アラーム時刻の指定はアナログ時計（ダイヤル）方式のみです。
	キーボード入力は表示崩れ・無応答の原因になったため、あえて使わない仕様にしています。
