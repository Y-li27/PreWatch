# Echo Clock App (Flutter)

Echo Show 5（Android 11改造）向けのシンプルな2×2ダッシュボードです。

## 表示内容
- 左上：大きな時計（時分秒）タップでアラーム設定
- 右上：日付・曜日（日本語）タップで今年の残り日数、長押しで今週の残り日数
- 左下：現在天気（Open-Meteo API・APIキー不要）最高・最低気温と降水確率つき。タップで明日の天気（降水確率つき）、長押しで地域変更
- 右下：ポモドーロタイマー（旧：画像スライドショー）

## ポモドーロタイマー（v3.2〜）
- タップ：スタート／一時停止
- 長押し：設定（集中 15/25/30/50分、休憩 5/10/15分、長い休憩 15/20/30分）とリセット
- 集中が終わると音が鳴って休憩が自動で始まります
- 休憩が終わると音が鳴って、集中はタップ待ちになります（夜通し回り続けないため）
- 集中4回ごとに長い休憩になります
- パネルの色で状態が分かります（集中中＝黄色 #F9E778、通常時＝ #5C526A。通常時は暗い背景に合わせて文字が白系になります）
- 終了音はアラームで選んだサウンドと同じものが鳴ります

## 使い方

1. Flutterがインストールされている環境でこのフォルダを開く
2. `flutter pub get`
3. 実機またはエミュレータで `flutter run`
4. APKを作りたい場合：`flutter build apk --release`

## アラーム音を変更したい場合

1. `assets` フォルダの `miracle.wav` / `eclair.wav` / `alcana.wav` / `all.wav` を、同じファイル名で好きな音声に差し替えてください。
2. 現在入っているのは仮のチャイム音（ピンポーン）です。そのまま使う分には問題ありません。

## v4.1.1の変更
- アラーム時刻をキーボードで直接入力しようとすると画面が固まったように見える問題を修正（キーボードにダッシュボードが押し潰されて overflow エラーが出続けていたため、キーボードは画面に重なって表示されるようにした）

## v4.1〜の変更
- 起動中は画面が消えないようになりました（Android側に常時表示の設定を追加）
- ポモドーロの巻き戻りを修正：動作中にアプリが閉じても、終了時刻から残り時間を計算して復帰します。閉じている間に終わっていた場合は、次のフェーズの頭で止まります
- アラームの一回限り仕様を統一：アプリが閉じている間にシステム通知で鳴り終わったアラームは、次回起動時に自動で解除され、翌日に再登録されません
- 明日の天気にも最低気温を表示しました
- 気温の単位が「°」だけになっていたのを「℃」に直しました（v4.0.1）

## v4.0〜の変更
- アラームをシステム通知にも登録するようになりました。アプリが閉じていても、設定時刻にAndroidの通知が届きます（アプリが開いているときは、今まで通りアプリ内で選んだ音が鳴ります）
- 通知とアプリ内表示の文面が、選んだ音ごとに変わります
  - システム：「時間です」
  - アンサー/ミスティック：「アンサー/ミスティックのウェイクアップタイム！」
  - エクレール：「エクレールのウェイクアップタイム！」
  - アルカナ：「アルカナのウェイクアップタイム！」
  - 全員：「みんなでウェイクアップタイム！」
- 初回起動時に「通知」と「正確なアラーム」の許可を求めるダイアログが出ることがあります。許可するとシステム通知が使えます（許可しなくてもアプリ内アラームは使えます）
- システム通知の音は端末の通知音です。選んだ音声ファイルそのものは通知では鳴らせません

## v3.3〜の変更
- 設定の保存：アラーム時刻・サウンド・地域・ポモドーロの時間と進み具合が、アプリを再起動しても残ります（ポモドーロは一時停止状態で復帰。完了セット数は日が変わるとリセット）
- 夜間モード：23時〜6時は自動で画面が暗くなります
- 焼け対策：表示全体が1分ごとに数pxだけずれます。有機EL（OLED）端末で使う場合のためです（Echo Showの液晶では気にしなくて大丈夫です）

## 注意
- 天気は30分ごとに自動更新します
- アラームはシステム通知にも登録されますが、ポモドーロはアプリが起動している間だけ動作します
